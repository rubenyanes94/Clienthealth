# Atención al Paciente — Centro Médico San Bernardino

Consola web de atención al paciente: bandeja de WhatsApp tipo CRM, casos con registro de eventos,
bot de primera línea con detección de urgencias e indicadores de tiempos y satisfacción.

- Arquitectura y plan por fases: [docs/INFRAESTRUCTURA.md](docs/INFRAESTRUCTURA.md)
- Comandos de desarrollo: [CLAUDE.md](CLAUDE.md)

Stack: FastAPI + SQLAlchemy + Postgres (Neon) · React + Vite + Tailwind v4 · Vercel Services.
